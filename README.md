# 精听英语库 Listening Lab

一个仿「nailaobao」的**实景英语精听网站**：左边播放英语视频，右边展示可切换的中英双语字幕，支持逐句复读与精听练习。纯静态网页，无需服务器、无需安装、无需联网（本地打开即可使用）。

---

## 功能特性

### 首页（课程库）
- 课程卡片网格：封面、课程序号、时长、标签、简介一目了然
- 自动统计课程节数、字幕句数、总时长、已完成数量
- 记录每门课的学习进度（未开始 / 已学百分比 / 已完成）
- 按钮随进度显示「开始学习 / 继续学习 / 复习本课」

### 播放器
- **左视频、右字幕**的经典精听布局
- 三种字幕模式一键切换：**双语 / 英文 / 中文**
- 点击任意字幕跳转到对应时间播放
- 当前播放句自动高亮，并在右侧列表中自动跟随滚动
- **单句循环**：反复听同一句
- **单句暂停**：每句播完自动停下，方便跟读
- 上一句 / 下一句快速切换
- 播放倍速：0.75x / 1.0x / 1.25x / 1.5x
- 字幕字号调节（小 / 默认 / 大）
- 可折叠当前句大字幕
- 顶部「上一课 / 下一课」在课程间切换
- 「重头」清除本课进度、回到开头
- **自动续播**：再次打开同一课，从上次位置继续
- 键盘快捷键：
  - `←` / `→`：上一句 / 下一句
  - `空格`：播放 / 暂停

## 如何添加 / 修改课程

所有课程内容都集中在 `assets/courses.js`，用任意文本编辑器打开即可修改。
文件本质是一个 `window.COURSES` 数组，每门课是一个对象：

```js
window.COURSES = [
  {
    "id": "lesson5",                 // 课程唯一标识（英文，不可重复）
    "title": "课程标题",
    "desc": "课程一句话简介",
    "tags": ["标签1", "标签2"],
    "src": "assets/lesson5.mp4",     // 视频文件路径
    "cover": "assets/cover5.jpg",    // 封面图片路径
    "duration": 300,                 // 视频总时长（秒）
    "count": 20,                     // 字幕句数（= subtitles 数组长度）
    "subtitles": [
      { "start": 0.0,  "end": 3.2,  "en": "Hello there.", "zh": "你好。" },
      { "start": 3.2,  "end": 7.8,  "en": "How are you?", "zh": "你好吗？" }
    ]
  }
];
```

字幕字段说明：
- `start` / `end`：该句开始与结束的时间（秒，可保留小数）
- `en`：英文字幕
- `zh`：中文字幕

**添加一门新课的步骤：**
1. 把视频（如 `lesson5.mp4`）和封面（如 `cover5.jpg`）放进 `assets/` 文件夹；
2. 在 `courses.js` 的数组里按上面格式追加一个课程对象；
3. 保存，刷新浏览器即可在首页看到新课。

> 提示：字幕时间轴可借助语音识别（ASR）工具生成，再按完整句子合并、补上中文翻译。

## 技术说明

- 纯 **原生 HTML + CSS + JavaScript**，单页应用（SPA），通过页面 hash 路由在「首页 / 播放器」之间切换
- **无任何前端框架、无构建步骤、无后端依赖**
- 字体：Lora（英文衬线）+ Noto Sans SC（中文），通过字体 CDN 加载，加载失败时自动回退到系统字体
- 学习进度仅保存在浏览器本地 `localStorage`（键名 `listening_lab_progress_v1`），不会上传到任何服务器；清除浏览器数据会同时清除进度
- 视频为 H.264 + AAC 编码，兼容主流浏览器

## 如何重新发布到线上

使用 `lark-cli` 将整个目录发布 / 更新为网页应用：

```bash
# 在包含 index.html 的目录的上一级执行（--dir 指向站点目录）
lark-cli apps +deploy --dir ./site --app-id app_17ejk9t378b
```

发布为异步过程，拿到 `release_id` 后轮询状态：

```bash
lark-cli apps +release-get --app-id app_17ejk9t378b --release-id <release_id>
```

待状态为 `finished` 即发布成功，网址保持不变。

**发布体积限制：** 单个 HTML ≤ 20 MiB，打包前总量 ≤ 200 MiB，打包后 zip ≤ 50 MiB。
若视频过大，需先压缩（降低分辨率 / 码率）再发布。
